# Ставочная пиццерия — сайт + приложение на телефон

Этот пакет превращает пиццерию в **настоящий сайт** (свой адрес, открывается у кого угодно
по ссылке) и в **устанавливаемое приложение** на телефон (иконка на домашнем экране,
открывается на весь экран, работает офлайн). Хостинг — бесплатный (GitHub Pages),
данные обновляются сами каждый день.

## Что внутри
- `pipeline.py` — движок (тянет коэффициенты, считает модель, оценивает прошлые прогнозы).
- `tmpl2.html`, `kupon.html`, `board_img.txt` — шаблоны и картинка штаба.
- `predictions_log.json` — журнал прогнозов (копит трек-рекорд/калибровку).
- `make_site.py` — собирает всё в папку `docs/` как готовый сайт (PWA).
- `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png` — «приложение» (PWA).
- `.github/workflows/refresh.yml` — робот, который каждый день пересобирает сайт.

## Что нужно (один раз, ~15 минут, всё бесплатно)
1. **Аккаунт GitHub** (github.com) — если нет, зарегистрируйся.
2. **Свой ключ the-odds-api** (у тебя уже есть) — из личного кабинета the-odds-api.com.
3. Ничего больше: ни сервера, ни оплаты, ни магазина приложений.

## Шаги
1. Создай на GitHub новый **приватный или публичный репозиторий** (напр. `pizzeria`).
2. Загрузи в него все файлы из этого пакета (кнопка *Add file → Upload files*, перетащи
   всё; папку `.github` тоже — GitHub сохранит структуру).
3. Добавь секрет с ключом: репозиторий → **Settings → Secrets and variables → Actions →
   New repository secret**. Имя: `ODDS_API_KEY`, значение — твой ключ the-odds-api.
4. Включи Pages: **Settings → Pages → Build and deployment → Source: Deploy from a branch →
   Branch: `main`, папка `/docs`** → Save.
5. Запусти сборку первый раз: вкладка **Actions → «Обновление пиццерии» → Run workflow**.
   Через 1–2 минуты в репозитории появится папка `docs/` с сайтом.
6. Готово. Твой адрес: `https://<твой-логин>.github.io/<имя-репозитория>/`
   (например `https://airat.github.io/pizzeria/`). Он **публичный** — открывается у любого,
   без входа в Claude.

## Установить как приложение на телефон
Открой этот адрес в браузере телефона и:
- **Android (Chrome):** меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- **iPhone (Safari):** кнопка «Поделиться» → «На экран Домой».

Появится иконка «Пиццерия». Запускается на весь экран, как обычное приложение,
последний собранный пул доступен даже офлайн.

## Обновление данных
Робот (GitHub Actions) пересобирает сайт **каждый день в 08:00 UTC** и коммитит свежий
`docs/`. Можно запустить вручную в любой момент: Actions → Run workflow.
Хочешь другую частоту — поменяй `cron` в `.github/workflows/refresh.yml`.

## Свой домен (по желанию)
Купи домен (~$8–12/год у любого регистратора) → Settings → Pages → Custom domain →
впиши домен и добавь у регистратора CNAME на `<логин>.github.io`. Тогда адрес будет
твой, напр. `pizza-stavki.ru`.

## Честные ограничения (не меняются от хостинга)
- Никаких гарантий прибыли. Модель футбола — fallback (без xG). Теннис/MMA — витрина рынка.
- Ставки микро, фокус на CLV и калибровку. Играй ответственно.
- the-odds-api free-тариф ~500 запросов/мес; ежедневная сборка тратит ~13 — с запасом.
